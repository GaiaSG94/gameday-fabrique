Borne

Planche V2 · page Jeu · 2026-11-18

Le jeu est une machine qu’on manipule. Une console d’atelier en acier brossé, vis apparentes, afficheur à segments, et quatre baies où l’on enfiche des cartouches ; chaque cartouche montre par son hublot la matière qu’elle produit, et le gros bouton RUN ne s’allume que quand la chaîne est complète. La lumière fait le jeu : tout ce qui est branché s’allume en ambre, le reste reste d’acier froid. De MemoryQuest : l’objet-borne posé dans une pièce sombre avec son halo, les boutons physiques ; d’Igloo : des modules assemblés dont les joints s’éclairent.
